# Equipper

Интеллектуальный организатор медиафайлов по устройствам и приложениям на основе алгоритма группировки.

## Описание

Equipper анализирует медиафайлы и автоматически организует их по логике камерных приложений (Photos, Halide, Blackmagic Camera, Moment, Filmic) и устройствам. Проект использует современную архитектуру с разделением обязанностей между детекторами, группировщиками и организатором файлов.

## Алгоритм работы

### Трехэтапная обработка

Equipper использует современный алгоритм группировки, состоящий из трех основных этапов:

#### Этап 1: Сканирование и группировка файлов

**Принцип группировки:**
- Анализирует все медиафайлы в директории (.HEIC, .JPG, .PNG, .DNG, .MOV, .AAE)
- Извлекает базовые имена файлов для группировки связанных файлов
- Создает группы файлов по связям и определяет принадлежность к приложениям

**Логика извлечения базовых имен:**
```
IMG_E7256.HEIC → базовое имя: "7256"
IMG_3431.AAE   → базовое имя: "3431" (группируется с IMG_3431.*)
IMG_7256.HEIC  → базовое имя: "7256"
A001_08041410_C001.MOV → базовое имя: "A001_08041410_C001"
```

**Пример группировки:**
```
Группа "7256":
├── IMG_7256.HEIC     (основной файл)
├── IMG_E7256.HEIC    (обработанный вариант)
└── IMG_7256.AAE      (метаданные редактирования)
```

#### Этап 2: Создание структуры устройств

**Определение устройств:**
- Извлекает EXIF метаданные из основных файлов групп
- Создает папки устройств на основе Make/Model из EXIF
- Нормализует названия iPhone (iPhone14,3 → iPhone 13 Pro Max)
- Создает подпапки для приложений в каждом устройстве

**Структура папок:**
```
Apple iPhone 13 Pro Max/
├── (корень устройства - для приложения Фото)
├── Halide/
├── Blackmagic Camera/
├── Moment/
└── Filmic/
```

#### Этап 3: Перемещение файлов группами

**Принцип перемещения:**
- Перемещает файлы целыми группами (сохраняет связи)
- Определяет папку назначения на основе классификации группы
- Файлы без EXIF данных попадают в основное устройство

### Классификация файлов по приложениям

#### 1. Приложение Фото (Photos)

**Live Photo (стандартные):**
```
IMG_7256.HEIC + IMG_E7256.HEIC + IMG_E7256.MOV
├── Основной снимок: IMG_7256.HEIC
├── Обработанный кадр: IMG_E7256.HEIC  
└── Видео компонент: IMG_E7256.MOV
→ Назначение: корень устройства
```

**Обычные снимки:**
```
IMG_7257.HEIC (одиночный файл без пары)
→ Назначение: корень устройства
```

**Обработанные файлы:**
```
IMG_E7258.JPG (без соответствующего IMG_7258.HEIC)
→ Назначение: корень устройства
```

#### 2. Halide

**Halide Portrait (характерная связка):**
```
IMG_7256.HEIC + IMG_E7256.HEIC (БЕЗ IMG_E7256.MOV)
├── Оригинал: IMG_7256.HEIC
└── Обработанный портрет: IMG_E7256.HEIC
→ Назначение: папка Halide
```

**Halide RAW:**
```
IMG_7257.DNG + IMG_7257.HEIC
├── RAW файл: IMG_7257.DNG
└── JPEG превью: IMG_7257.HEIC
→ Назначение: папка Halide
```

**Одиночные DNG файлы:**
```
IMG_7258.DNG (без парного HEIC)
→ Назначение: корень устройства (приложение Фото)
```

#### 3. Blackmagic Camera

**Определение через EXIF:**
- Поле Software содержит "blackmagic"
- Все файлы группы → папка Blackmagic Camera

**Пример:**
```
A001_08041410_C001.MOV (Software: "Blackmagic Cam 2.3.000047")
→ Назначение: папка Blackmagic Camera
```

#### 4. Moment

**Определение только через EXIF:**
1. **EXIF Software:** "moment" в поле Software
2. **EXIF Make:** "Moment" в поле Make

**Пример:**
```
IMG_7259.DNG (Software: "Moment Pro Camera")
→ Назначение: папка Moment
```

#### 5. Filmic Pro

**Определение только через EXIF:**
1. **EXIF Make:** "Filmic" в поле Make  
2. **EXIF Software:** "filmic" в поле Software

**Пример:**
```
08042025_141023.MOV (Software: "Created with Filmic Legacy 6.23.1 build 136760")  
→ Назначение: папка Filmic
```

### Специальные случаи обработки

#### AAE файлы (метаданные редактирования)

**Принцип:** AAE файлы всегда следуют за основными файлами своей группы
```
IMG_7256.HEIC → Halide
IMG_7256.AAE  → Halide (следует за основным файлом)
```

#### Файлы без EXIF данных

**Обработка:**
- Файлы от приложений (без Make/Model в EXIF) → основное устройство
- Классификация по логике приложений сохраняется
- Назначаются в первое найденное устройство или дефолтное

## Требования

- Python 3.6+ (проверенная совместимость до Python 3.12)
- ExifTool (устанавливается системно)

### Установка ExifTool

**macOS:**
```bash
brew install exiftool
```

**Ubuntu/Debian:**
```bash
sudo apt-get install libimage-exiftool-perl
```

**Windows:**
Скачайте с [официального сайта](https://exiftool.org/)

## Использование

### Базовое использование
```bash
# Прямой запуск
python3 equipper.py /path/to/photos

# После установки
equipper /path/to/photos
```

### Режимы работы

#### Режим 1: Одна папка с файлами
```bash
equipper ~/Pictures/Camera_Roll
```
Все медиафайлы в указанной папке обрабатываются как одна группа.

#### Режим 2: Папка с подпапками  
```bash
equipper ~/Pictures/Multiple_Exports
```
Каждая подпапка обрабатывается отдельно, сохраняя изоляцию между экспортами.

### Поддерживаемые форматы

**Фотографии:** `.HEIC`, `.JPG`, `.PNG`, `.DNG`  
**Видео:** `.MOV`  
**Метаданные:** `.AAE`

## Безопасность

⚠️ **Внимание:** Скрипт перемещает файлы без создания резервных копий
- Рекомендуется создать резервную копию перед использованием
- Файлы не изменяются, только перемещаются и группируются
- Пустые папки автоматически удаляются

## Архитектура

### Модульная структура
```
equipper/
├── __init__.py          # Экспорт основного класса
├── equipper.py          # Точка входа, CLI интерфейс
├── organizer.py         # Основная логика FileOrganizer
├── detectors.py         # Классификация и группировка  
├── constants.py         # Константы приложений и форматов
├── pyproject.toml       # Конфигурация проекта
├── requirements-dev.txt # Зависимости для разработки  
└── README.md           # Документация
```

### Основные классы

**FileOrganizer** - центральный класс организации с поддержкой двух режимов работы  
**OrganizationPipeline** - координатор этапов обработки файлов  
**FileGrouper** - группировка файлов по связям с EXIF анализом  
**FileGroup** - представление группы связанных файлов  
**FileTypeDetector** - определение типов медиафайлов по расширениям  
**PhotosAppFileDetector** - сложная логика определения файлов из приложения Фото  
**BlackmagicDetector** - специализированный детектор Blackmagic через EXIF  
**HalideDetector** - определение файлов Halide по характерным признакам  

## Разработка

### Качество кода

```bash
# Проверка кода
ruff check .

# Форматирование
ruff format .
```

### Запуск тестов
```bash
# Создание тестовых файлов
mkdir tmp
cd tmp  
touch IMG_3431.HEIC IMG_E3431.HEIC IMG_3431.AAE

# Тестирование
cd ..
python3 equipper.py tmp
```

### Добавление новых приложений

1. Добавить константу в `constants.py`:
```python
class AppNames:
    NEW_APP = "New App"
```

2. Расширить логику в `detectors.py`:  
```python
def _determine_group_app_type(self, group):
    # Добавить проверки для нового приложения
    if self._is_new_app_file(group):
        return AppNames.NEW_APP
```

## Особенности реализации

### Обработка ошибок
- Все детекторы инициализируются с обработкой ошибок и fallback механизмами
- EXIF операции обернуты в try/catch блоки для предотвращения сбоев
- Файлы без EXIF данных корректно обрабатываются и назначаются дефолтному устройству

### Нормализация устройств Apple
- Поддержка полного спектра iPhone моделей с iPhone 6 до iPhone 15 Pro Max
- Автоматическое преобразование технических идентификаторов (iPhone14,3 → iPhone 13 Pro Max)
- Фильтрация приложений от реальных устройств в EXIF данных

### Производительность
- Batch операции для создания папок и перемещения файлов
- Эффективная группировка файлов по базовым именам
- Минимальное количество EXIF операций через кэширование в группах
